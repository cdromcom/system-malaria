You are extracting a discourse graph from the **System Public Graph**, a corpus of quantitative
findings mined from peer-reviewed research. This is not PDF extraction. The source is an API
whose records are already atomic, so the work is not reading papers — it is **entity resolution
and honest accounting**, because the graph stores one free-text variable per paper and no
canonical entities.

Read [[Skill-harvest]] for the API recipe, [[Skill-synthesis]] for grouping and alert rules, and
[[Skill-templates]] for node formats.

## The core insight that shapes everything

A "variable" in this graph is one paper's exact phrasing: `Pfmdr1 N86`, `isolates with crt T76`,
`Patients with k13 F446I mutation [vs Patients without k13 mutations]`. There are 5,654,715
variables against 5,944,001 associations — roughly **one variable per finding**.

So there is no node to query. A marker's evidence has to be assembled from scattered strings, and
every count you report depends on the patterns you chose. Say so, every time.

## Workflow at a glance

1. **Probe the API** before trusting any documentation. Confirm field names on both list and
   detail endpoints, and check whether `search` filters or ranks.
2. **Sweep variable names** with a broad term list — gene names, protein names, every codon
   mutation, haplotype names, and both American and British spellings of every outcome word.
3. **Prune substring collisions.** The search is substring matching, so short abbreviations
   collide with unrelated medicine. Measure the collision rate; do not just filter it away.
4. **Measure grounding, then ignore it.** Report what fraction of variables carry a `concept_id`
   and what those concepts are. Do not expand through concepts.
5. **Pull associations** for marker variables only, retrying flaky 500s.
6. **Fetch studies, then publication dates from PubMed.** The graph has no dates. Without this
   step there is no time dimension and no project.
7. **Classify malaria-relevant vs off-target**, keeping the rejects and reporting the ratio.
8. **Write nodes** — one EVD per association, CLM per marker × outcome theme with ≥2 findings,
   QUE from the brief, CVT per limitation discovered.
9. **Write citation-only source stubs.** DOI, PubMed ID, journal, date, population string. Never
   article text.
10. **Cross-check against the Dataverse deposit** and carry a verification state on every finding.
11. **Regenerate `DGRAPH.md`** and log everything in `LOG.md` and `History.md`.

## Key principles

1. **Report the denominator.** "225 findings" is meaningless without "from 923 anchor variables,
   of which 42 failed, out of 2,055 matched by 202 search terms."
2. **Keep the rejects.** The off-target rate is a finding. In this corpus 323 of 1,184 harvested
   associations were human ABCB1, tuberculosis or oncology — that ratio belongs in the pitch.
3. **Never let a filter run unexamined.** Print a sample of what each filter dropped. A filter
   you have not looked at has an unknown error rate.
4. **Check whether a failure is deterministic before changing retry policy.** A global fix for
   one endpoint's permanent 500s once destroyed 62% of the data from another endpoint's
   intermittent 500s. See [[CVT - Roughly 20 percent of API associations are mis-extracted]] and
   `LOG.md`.
5. **An aggregation claim is not a paper's claim.** CLM nodes here assert that the graph *holds*
   N findings, never that the effect is real, directional or significant.
6. **Verification state travels with the value.** Given a documented ~20% extraction error rate,
   an unverified statistic must never render as a bare number in an alert.
7. **Coverage gaps are results, not failures.** Pfkelch13 having 21 findings while PfCRT has 77
   is the most publishable thing in this vault.
8. **Citation data only in `source/`.** This vault is not a library. Link out.
9. **Everything reproducible from `scripts/`.** If a number in a node cannot be regenerated by
   re-running a script, it does not belong in a node.

## What this skill does not do

It does not read PDFs, render screenshots, or quote article text. The graph is the source of
record and the citation is the pointer. If you need a quote, open the DOI.

It also does not pool effects or run a meta-analysis. The statistic families are mixed and the
directions unknown; pooling them would be the single easiest way to produce a confident wrong
answer.
